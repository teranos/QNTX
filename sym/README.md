# sym - QNTX segments

"ATS and QNTX go, they own the segments, the two letter abbreviations"

"an sg is a segment like as is of by at am i"

| Segment | Meaning |
|---------|---------|
| `i` | Self — your vantage point into QNTX |
| `am` | Being — the node, the server |
| `ix` | Ingest — import external data |
| `ax` | Expand — surface related context |
| `as` | Assert — emit an attestation |
| `is` | |
| `of` | Membership — element-of/belonging |
| `by` | Actor — catalyst/origin of action |
| `at` | Event — temporal marker |
| `so` | Therefore — consequent action |
| `se` | Semantic — meaning-based search and entailment |

Glyphs are the UI's: [`ts/sym.ts` in QNTX-Web](https://github.com/teranos/QNTX-Web/blob/main/ts/sym.ts) is the symbol, the one place a segment is mapped to a glyph.
