# USER connects ChatGPT

As USER, in Connectors, i press ChatGPT

As USER i give the callback URL ChatGPT shows me: ChatGPT makes one per connector, so the node cannot know it

As USER i get the server URL, the client id and the client secret, and the token endpoint auth method, right there

As USER i set ChatGPT up with those, say yes at my passkey, and ChatGPT reaches the namespace i am standing in

"you can connect multiple chatgpt accounts"

As USER i connect a second ChatGPT account the same way, and it is its own connection
